# Machine Learning Study Projects

A collection of hands-on machine learning and deep learning projects built for study and experimentation. Each folder is a self-contained project tackling a different problem — from computer vision and NLP to predictive modeling — with its own dataset and code.

## Computer Vision

* **[cancer-detection](./cancer-detection)** — Cancer image classification using CNNs and Transfer Learning (MobileNetV2, Xception), with data augmentation and fine-tuning.
* **[covid-detection](./covid-detection)** — COVID-19 detection from medical images using CNNs and Transfer Learning.
* **[handwritten-digit-recognition](./handwritten-digit-recognition)** — Handwritten digit recognition (MNIST) with a Multilayer Perceptron (MLP).

## Natural Language Processing

* **[detect-spam-mail](./detect-spam-mail)** — Email spam classification comparing LSTM, BiLSTM, and the Universal Sentence Encoder.
* **[detect-spam-sms](./detect-spam-sms)** — SMS spam detection using deep learning text models.
* **[text-classification](./text-classification)** — Multiclass text categorization with Naive Bayes.
* **[flipkart-sentiment](./flipkart-sentiment)** — Sentiment analysis on Flipkart product reviews.
* **[twitter-sentiment](./twitter-sentiment)** — Sentiment analysis on tweets.

## Predictive Modeling

* **[stock-prediction-1](./stock-prediction-1)** — Predicting stock price movement (Tesla) with Logistic Regression, SVM, and XGBoost, evaluated by ROC-AUC.

## Tech Stack

**Languages:** Python  
**ML & DL:** scikit-learn, XGBoost, TensorFlow/Keras  
**Data:** Pandas, NumPy  
**NLP:** LSTM, BiLSTM, Universal Sentence Encoder  
**Computer Vision:** CNN, Transfer Learning (MobileNetV2, Xception)

## Getting Started

Each project folder is independent. Clone the repository and open any folder to explore that project on its own.

```bash
git clone https://github.com/caio-fodra/<repo-name>.git
```
